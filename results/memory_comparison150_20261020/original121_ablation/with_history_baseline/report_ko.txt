전체 121문제 Single/Dual 최종 구조 평가

기존 62문제 결과를 보존하고 남은 59문제를 새로 실행했다. 고유 ID 121개, 구조별 121회, 합계 242개 실행.
사용자가 언급한 기존 61개·추가 60개는 실제 저장된 ID 기준 기존 62개·추가 59개로 정정했다. 중복을 추가하지 않았다.
전체 데이터의 증명 42개·반증 79개를 모두 포함한다. 초기 62개의 균형 표집과 달리 이번 최종 집계는 데이터 전체의 분포다.

최종 구조:
- Orchestrator: openai/gpt-6-luna-pro. Natural/Generator/Repair: openai/gpt-6-luna.
- OpenAI Flex 고정, worker reasoning=none, 모델/제공자 fallback 없음.
- Orchestrator는 이전 전략·자연어 추론·Lean 코드를 참고한다. Single은 자기 실행 이력, Dual은 양쪽의 이전 라운드 이력이다.
- Orchestrator 메모리에 Repair 지침·컴파일 로그를 추가하지 않는다. Natural은 Lean 전략 없이 독립 추론한다.
- Generator는 Lean 전략과 자연어 추론을 받고, Repair는 해당 Generator 재시도에 쓸 retry_guidance 하나만 출력한다.
- Single은 라운드마다 증명/반증을 선택하고 Dual은 두 고정 경로를 유지한다. 성공은 고정 목표의 Lean 검증으로만 인정한다.
- 최대 3라운드, 경로당 라운드별 3시도: Single 최대 9회, Dual 합계 최대 18회.
- 기존 62개와 추가 59개 실행의 핵심 Python 파일 12개는 원래 baseline snapshot과 일치한다.

한계:
- This is a full 121-case dataset evaluation, not a newly untouched holdout.
- Original 62 results and earlier development results were inspected before final architecture selection.
- Remaining 59 include 22 previously used development cases; all 59 receive fresh runs here. Other prior scores are not pooled.
- One run per architecture per problem; related textbook exercises may not be independent.
- Single and Dual preserve unequal maximum 9/18 attempt budgets. Report actual checks, tokens and costs.
- Reported results certify the supplied formal goals, not independent equivalence to the informal textbook statements.
- Original 30 jobs were sequential; later 32 used two concurrent jobs; final 59 use four concurrent jobs with globally serialized Lake builds. Wall times are not a controlled latency comparison.
- 초기 62개와 개발 결과를 확인한 뒤 최종 구조를 선택했다. 완전히 보지 않은 holdout의 성능으로 해석하지 않는다.
- 목표 형식화의 타당성과 엄격/비엄격 조건 등 원문과의 대응은 별도 검토 대상이다. 형식 목표에 맞는 증명을 검증했다.
- Single/Dual의 최대 계산 예산은 다르다. 이 결과만으로 경로 공유의 인과 효과나 두 구조의 동등성을 단정하지 않는다.
